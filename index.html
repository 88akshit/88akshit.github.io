SECTION 01 — README

Two disciplines, one profile

My path ran through Infosys, Oracle, Cisco, and VMware before I moved into battery-specific software at TWAICE, then into leading platform development at BMW Group. That order matters — I arrived at batteries already knowing how to build resilient software, then spent years earning the electrochemistry.

Today I lead Cell Builder, a physics-based calculator for prismatic, cylindrical, and pouch cell design, and Material Explorer, a discovery tool for best-fit battery materials — both inside Cell Intelligence, BMW's Battery Analytics Platform.

I manage a team of interns across battery cell research workflows, and work daily across React, TypeScript, Java Spring Boot, Python, AWS, and LLM-driven RAG pipelines.

"Dive deep into solutions and improvise on architecture, code quality, for future-proof business needs and maintainability."

SECTION 02 — SHIPPED

What I've built at BMW

Cell Intelligence supports cell engineering and research for next-generation BMW vehicles. Here's what I've led inside it.

MODULE 01Cell Builder

Physics-based cell design calculator

Creates Prismatic, Cylindrical & Pouch cell designs at OEM/supplier level. Takes material and geometric inputs and computes the full cell performance budget — capacity, energy density, mass, stack thickness, irreversible losses, and more.

Physics-informed React + TypeScript Java Spring Boot
MODULE 02Material Explorer

Best-fit materials discovery tool

Exploration engine for finding best-fitted battery materials for cell manufacturing — built on a hybrid SQL + RAG architecture over proprietary materials data.

RAG pipelines LLM APIs MySQL
